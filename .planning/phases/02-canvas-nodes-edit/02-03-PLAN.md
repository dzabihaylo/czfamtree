  <behavior>
    - `useSaveQueue(treeId)` returns a stable object `{ enqueueField, enqueueMove, flush, retry }` across re-renders (use `useRef` to hold the mutable queue, `useMemo` for the return).
    - `enqueueField(personId, field, value)`:
      - Stores `value` under a per-person pending-patch map: `pending[personId][field] = value`.
      - Schedules a per-person debounce timer (400ms). Resetting any field on that person restarts the timer.
      - When the timer fires: capture the current `pending[personId]`, clear it, transition pill to `'saving'`, await `updatePerson(treeId, personId, capturedPatch)`, then either `'saved'` (+ 1400ms `'idle'` revert) or `'error'`.
      - If a save is already in-flight for that person: the new `pending` merges in; when the in-flight resolves, if `pending` is non-empty, schedule a new in-flight immediately (no new debounce wait — SAVE-04 serial queue).
    - `enqueueMove(personId, x, y)`:
      - Behaves as a special case of enqueueField with no debounce (drag-end fires immediately, per UI-SPEC §4 + §7 rule 8).
      - Funnels through the SAME per-person serial queue so a drag save cannot race a field save for the same person.
    - `flush(personId)`:
      - Synchronously cancels the debounce timer AND immediately fires the save for whatever is in `pending[personId]` (UI-SPEC §7 rule 6 — panel close flushes).
      - Returns `void` (not a Promise; the resulting save still surfaces via the pill/toast).
    - `retry(personId)`:
      - Only valid when pill state is `'error'`. Takes the most recent failed payload (stored in `lastFailedPatch[personId]`) and re-enqueues it, transitioning pill to `'saving'`.
      - If no prior failed payload exists, no-op.
    - The hook writes to the store via the `setSaveState` setter. It reads the current `treeId` from the `treeId` parameter (closure) — does NOT subscribe to `treeId` changes (the panel unmounts + remounts if the tree changes, so the hook re-runs).
    - All timers cleared on `useEffect` cleanup.
  </behavior>

    ```typescript
    'use client';

    import { useEffect, useMemo, useRef } from 'react';
    import { useTreeStoreApi } from '@/lib/store/tree-store';
    import { updatePerson, movePerson } from '@/app/actions/people';
    import type { PersonPatch } from '@/lib/schemas/person';

    const DEBOUNCE_MS = 400;
    const SAVED_LINGER_MS = 1400;

    type PersonId = string;

    type PerPerson = {
      // Dirty patch not yet sent (merges when new edits arrive during debounce or in-flight).
      pending: Partial<PersonPatch>;
      // Debounce timer handle.
      timer: ReturnType<typeof setTimeout> | null;
      // In-flight Promise — non-null while the server call is running.
      inFlight: Promise<void> | null;
      // Last payload that failed (for retry()).
      lastFailedPatch: Partial<PersonPatch> | null;
      // Linger timer that schedules the 'saved' -> 'idle' transition.
      lingerTimer: ReturnType<typeof setTimeout> | null;
    };

    export type SaveQueue = {
      enqueueField: <K extends keyof PersonPatch>(personId: PersonId, field: K, value: PersonPatch[K]) => void;
      enqueueMove: (personId: PersonId, x: number, y: number) => void;
      flush: (personId: PersonId) => void;
      retry: (personId: PersonId) => void;
    };

    export function useSaveQueue(treeId: string): SaveQueue {
      const storeApi = useTreeStoreApi();
      const byPerson = useRef<Map<PersonId, PerPerson>>(new Map());

      // Cleanup on unmount — clear all timers.
      useEffect(() => {
        const map = byPerson.current;
        return () => {
          for (const entry of map.values()) {
            if (entry.timer) clearTimeout(entry.timer);
            if (entry.lingerTimer) clearTimeout(entry.lingerTimer);
          }
        };
      }, []);

      function getEntry(personId: PersonId): PerPerson {
        let e = byPerson.current.get(personId);
        if (!e) {
          e = { pending: {}, timer: null, inFlight: null, lastFailedPatch: null, lingerTimer: null };
          byPerson.current.set(personId, e);
        }
        return e;
      }

      async function runSave(personId: PersonId): Promise<void> {
        const e = getEntry(personId);
        // Capture and clear pending BEFORE the await so new edits merge into a fresh pending.
        const patch = e.pending;
        e.pending = {};
        if (Object.keys(patch).length === 0) {
          e.inFlight = null;
          return;
        }

        const { setSaveState } = storeApi.getState();
        setSaveState(personId, 'saving');

        try {
          await updatePerson(treeId, personId, patch as PersonPatch);
          // Successful ACK — pill flips green (SAVE-02).
          storeApi.getState().setSaveState(personId, 'saved');
          e.lastFailedPatch = null;

          // SAVE-03: saved lingers 1.4s then returns to idle — unless another edit
          // arrived during the save (pending is non-empty) in which case we chain.
          if (e.lingerTimer) clearTimeout(e.lingerTimer);
          e.lingerTimer = setTimeout(() => {
            if (storeApi.getState().saveStateByPersonId[personId] === 'saved') {
              storeApi.getState().setSaveState(personId, 'idle');
            }
            e.lingerTimer = null;
          }, SAVED_LINGER_MS);
        } catch (_err) {
          storeApi.getState().setSaveState(personId, 'error');
          e.lastFailedPatch = patch;
          // Do NOT rethrow — the SaveErrorToast subscribes to 'error' and renders Retry.
        } finally {
          // Chain: if pending accumulated during the save, run again immediately (SAVE-04).
          if (Object.keys(e.pending).length > 0) {
            e.inFlight = runSave(personId);
          } else {
            e.inFlight = null;
          }
        }
      }

      function scheduleDebounce(personId: PersonId) {
        const e = getEntry(personId);
        if (e.timer) clearTimeout(e.timer);
        e.timer = setTimeout(() => {
          e.timer = null;
          // If a save is in-flight, the patch merge is already in e.pending and will
          // be picked up in the chain-finally. Only start a new in-flight when idle.
          if (!e.inFlight) {
            e.inFlight = runSave(personId);
          }
        }, DEBOUNCE_MS);
      }

      const api = useMemo<SaveQueue>(() => ({
        enqueueField(personId, field, value) {
          const e = getEntry(personId);
          (e.pending as any)[field] = value;
          scheduleDebounce(personId);
        },
        enqueueMove(personId, x, y) {
          const e = getEntry(personId);
          e.pending.x = x;
          e.pending.y = y;
          // No debounce — fire immediately or chain onto existing in-flight.
          // NB: PanZoomWrapper in Plan 02 calls movePerson directly for drag end.
          //     enqueueMove is here as an opt-in path for future Plan 03/4/5 consumers
          //     that want to funnel moves through the same serial queue as field edits.
          if (!e.inFlight) {
            e.inFlight = runSave(personId);
          }
        },
        flush(personId) {
          const e = byPerson.current.get(personId);
          if (!e) return;
          if (e.timer) {
            clearTimeout(e.timer);
            e.timer = null;
          }
          // Fire whatever is pending, chaining onto in-flight if any.
          if (!e.inFlight && Object.keys(e.pending).length > 0) {
            e.inFlight = runSave(personId);
          }
        },
        retry(personId) {
          const e = byPerson.current.get(personId);
          if (!e || !e.lastFailedPatch) return;
          // Merge failed payload back into pending and fire.
          Object.assign(e.pending, e.lastFailedPatch);
          e.lastFailedPatch = null;
          if (!e.inFlight) {
            e.inFlight = runSave(personId);
          }
        },
        // eslint-disable-next-line react-hooks/exhaustive-deps
      }), [treeId, storeApi]);

      return api;
    }
    ```

    - Two concurrent `runSave` invocations for the same person are impossible because we check `!e.inFlight` before assigning.

    'use client';
    import { useEffect, useRef, useState } from 'react';
    import { cn } from '@/lib/utils/cn';

    type Props = {
      label: string;
      value: string;
      onCommit: (v: string) => void;
      placeholder?: string;
      /** `mono` uses JetBrains Mono (for year inputs). Default sans. */
      variant?: 'text' | 'mono' | 'year';
      /** HTML inputMode for keyboards on year inputs. */
    };

    const DEBOUNCE_MS = 400;

    export default function FieldInput({ label, value, onCommit, placeholder, variant = 'text' }: Props) {
      const [local, setLocal] = useState(value);
      const timerRef = useRef<ReturnType<typeof setTimeout> | null>(null);

      // If the parent's `value` changes while not editing (e.g. Realtime Phase 5 push),
      // re-sync local. Skip during active debounce to avoid clobbering in-progress typing.
      useEffect(() => {
        if (!timerRef.current) setLocal(value);
      }, [value]);

      useEffect(() => () => { if (timerRef.current) clearTimeout(timerRef.current); }, []);

      const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
        const v = e.target.value;
        setLocal(v);
        if (timerRef.current) clearTimeout(timerRef.current);
        timerRef.current = setTimeout(() => {
          timerRef.current = null;
          onCommit(v);
        }, DEBOUNCE_MS);
      };

      const handleBlur = () => {
        // On blur, flush debounce immediately.
        if (timerRef.current) {
          clearTimeout(timerRef.current);
          timerRef.current = null;
          onCommit(local);
        }
      };

      return (
        <div className="block">
          <label className="block font-mono text-[11px] uppercase tracking-[0.1em] text-ink-3 mb-[6px]">
            {label}
          </label>
          <input
            className={cn(
              'w-full border border-rule bg-bg-card text-[14px] text-ink',
              'focus:border-accent focus:outline-none',
              (variant === 'mono' || variant === 'year') && 'font-mono',
            )}
            inputMode={variant === 'year' ? 'numeric' : 'text'}
            pattern={variant === 'year' ? '[0-9]{0,4}' : undefined}
            maxLength={variant === 'year' ? 4 : undefined}
            style={{ padding: '8px 10px' }}
            value={local}
            placeholder={placeholder}
            onChange={handleChange}
            onBlur={handleBlur}
          />
        </div>
      );
    }

    'use client';
    import { useTreeStore, type SaveState } from '@/lib/store/tree-store';

    type Props = {
      personId: string;
      onRetry: () => void;
    };

    type Style = { dot: string; text: string; border: string; bg: string; label: string };

    function styleFor(state: SaveState): Style {
      switch (state) {
        case 'saving':
          return {
            dot: 'var(--ink-3)',
            text: 'var(--ink-3)',
            border: 'var(--rule)',
            bg: 'var(--bg-soft)',

            dot: 'var(--success)',
            text: 'var(--success)',
            border: 'var(--success)',
            bg: 'var(--save-saved-bg)',
            label: 'Saved',

            dot: 'var(--danger)',
            text: 'var(--danger)',
            border: 'var(--danger)',
            bg: 'var(--save-error-bg)',
            label: 'Couldn\u2019t save',

        default:
          return {
            dot: 'var(--ink-3)',
            text: 'var(--ink-3)',
            border: 'var(--rule)',
            bg: 'var(--bg-soft)',
            label: 'Auto-saves',
          };
      }

        <>
          <span
            aria-hidden="true"
            style={{
              width: 6,
              height: 6,
              borderRadius: '50%',
              background: s.dot,
              display: 'inline-block',
            }}
          />
          <span>{s.label}</span>
        </>
      );

      if (state === 'error') {
        return (

            type="button"
            onClick={onRetry}
            role="status"
            aria-live="polite"
            aria-atomic="true"
            aria-label="Retry saving — last save failed"

              padding: '2px 6px',
              background: s.bg,
              border: `1px solid ${s.border}`,
              color: s.text,
              transition: 'all 0.2s ease',
            }}
          >
            {content}
          </button>
        );
      }

      return (
        <span
          role="status"
          aria-live="polite"
          aria-atomic="true"
          className="inline-flex items-center gap-[4px] font-mono text-[11px] tracking-[0.08em]"
          style={{
            padding: '2px 6px',
            background: s.bg,
            border: `1px solid ${s.border}`,

            transition: 'all 0.2s ease',
          }}
        >
          {content}
        </span>

    **4a. Create `components/canvas/SaveErrorToast.tsx`.**

    Subscribes to any person whose save state is `'error'`. Shows a single toast with the last-errored person's name + field-agnostic copy. Auto-dismiss after 4.4s. Retry button calls `queue.retry(personId)` (passed as prop).

    ```tsx
    'use client';
    import { useEffect, useMemo, useState } from 'react';
    import { useTreeStore } from '@/lib/store/tree-store';

    const TOAST_DISMISS_MS = 4400;

    type Props = {
      onRetry: (personId: string) => void;
    };

    export default function SaveErrorToast({ onRetry }: Props) {
      const saveStateByPersonId = useTreeStore(s => s.saveStateByPersonId);
      const peopleRecord = useTreeStore(s => s.people);

      // Find the FIRST (or most recent — store is a plain Record, order indeterminate)
      // person with 'error' state. If multiple concurrent errors, the toast collapses
      // to the last-errored one; subsequent Retry / success calls close it.
      const errorPersonId = useMemo(() => {
        for (const [id, state] of Object.entries(saveStateByPersonId)) {
          if (state === 'error') return id;
        }
        return null;
      }, [saveStateByPersonId]);

      const person = errorPersonId ? peopleRecord[errorPersonId] : null;

      const [dismissed, setDismissed] = useState(false);

      // Reset dismissed flag when a fresh error surfaces for a new person.
      useEffect(() => {
        setDismissed(false);
      }, [errorPersonId]);

      // Auto-dismiss timer.
      useEffect(() => {
        if (!errorPersonId || dismissed) return;
        const t = setTimeout(() => setDismissed(true), TOAST_DISMISS_MS);
        return () => clearTimeout(t);
      }, [errorPersonId, dismissed]);

      if (!errorPersonId || !person || dismissed) return null;

      const displayName = person.name || 'Unnamed';

      return (
        <div
          role="alert"
          aria-live="assertive"
          className="fixed left-1/2 flex items-center gap-[12px] font-sans text-[13px] text-bg-card bg-ink"
          style={{
            bottom: 80,
            transform: 'translateX(-50%)',
            padding: '10px 16px',
            zIndex: 200,
            boxShadow: '3px 3px 0 var(--accent)',
          }}
        >
          <span>Couldn&apos;t save changes for {displayName}</span>
          <button
            type="button"
            onClick={() => {
              onRetry(errorPersonId);
            }}
            aria-label={`Retry saving ${displayName}`}
            className="font-semibold hover:underline"
            style={{ color: 'var(--accent)' }}
          >
            Retry
          </button>
          <button
            type="button"
            onClick={() => setDismissed(true)}
            aria-label="Dismiss error"
            className="text-bg-card opacity-70 hover:opacity-100"
          >
            ×
          </button>
        </div>
      );
    }
    ```

    Notes:
    - UI-SPEC Copywriting suggests `Couldn't save {fieldLabel}` for field saves and `Couldn't save move for {name}` for drag failures. Without tracking which field failed (useSaveQueue only stashes the merged patch), a person-level message is accurate and less noisy. Document this simplification in SUMMARY; Plan 03 can refine if QA requests it.
    - `role="alert"` + `aria-live="assertive"` so SR users hear the error even without focus change (UI-SPEC Accessibility).
    - The X close button lets users dismiss before the 4.4s timer if they see the toast immediately and want it gone.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Panel field → useSaveQueue → updatePerson Server Action | Untrusted user input (typed values) crosses from the browser, through a Zustand-hook buffer, into a Server Action. Plan 01 already validates inputs via `PersonPatchSchema.strict().parse()` — this plan must not bypass that validator. |
| Panel Remove button → removePerson Server Action | Client invokes deletion; RLS + auth check in Plan 01 enforce authorization. |
| Client confirm dialog | `window.confirm(...)` is a trusted browser primitive — cannot be skipped or spoofed by page JS (modal is blocking, OS-level). Accepted as the Phase 2 security ceiling for destructive actions. |
